SCHOOL GALLERY PHOTOS
=====================

Put the school's real photos in the folders here. The Gallery page picks them
up automatically - no code changes needed.

Folders (each one is a filter button on the Gallery page):

  classroom-life    lessons, reading, computer room, science
  islamic-studies   Qur'an class, prayers, Jumu'ah, theology lessons
  school-life       assembly, nursery, boarding, meals, compound
  co-curricular     sports day, football, netball, swimming, MDD, clubs
  events            speech day, Eid, visitation day, tours, graduation

Rules:

  * Use .jpg, .jpeg, .png or .webp files.
  * The file name becomes the caption under the photo:
        sports-day-2026.jpg   ->   "Sports day 2026"
        p7-candidates.jpg     ->   "P7 candidates"
  * Landscape photos look best (they are shown at 4:3).
  * Keep each photo under about 500 KB so the page loads quickly on phones.
  * Only use photos the school has permission to publish, especially of children.

Until at least one photo is added, the Gallery page shows "Photo coming soon"
placeholder tiles.
